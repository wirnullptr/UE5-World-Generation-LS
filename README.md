# UE5-Gameplay-Systems-BP

Сборка независимых игровых систем на Blueprint и GAS (Gameplay Ability System) для Unreal Engine 5. Каждая система проектирована как модульная и может использоваться отдельно.

## Атрибуты

Динамическая система атрибутов на основе GAS, вдохновлённая Elden Ring. **Основные атрибуты** прокачиваются вручную, **побочные** рассчитываются автоматически в зависимости от основных.

### Основные атрибуты

Прокачиваются напрямую игроком:
- **Strength** — физическая сила, влияет на урон и грузоподъёмность
- **Agility** — ловкость, влияет на скорость и крит-шанс
- **Intelligence** — интеллект, влияет на магический урон и ёмкость маны
- **Endurance** — выносливость, влияет на выносливость и максимальное здоровье
- **Obsession** — одержимость, влияет на специальные статусы и эффекты

### Побочные атрибуты

Рассчитываются автоматически:
- **Health / Max Health** — из Endurance
- **Health Regeneration** — из Endurance + Intelligence
- **Mana / Max Mana** — из Intelligence
- **Mana Regeneration** — из Intelligence
- **Stamina / Max Stamina** — из Endurance + Agility
- **Stamina Regeneration** — из Agility
- **Physical Damage** — из Strength + Agility
- **Magic Damage** — из Intelligence
- **Critical Chance** — из Agility
- **Critical Damage** — из Strength + Agility
- **Armor / Defense** — из Endurance
- **Magic Resistance** — из Intelligence
- **Attack Speed** — из Agility
- И другие...

### Архитектура

- **GAS AttributeSet** — базовая хранилище всех атрибутов
- **Data Asset конфиги** — таблицы, где указано, какой основной атрибут на что влияет и с каким коэффициентом
- **Real-time Update** — побочные атрибуты пересчитываются в реальном времени при изменении основных
- **Модульность** — легко добавлять новые атрибуты и связи между ними через конфиги, без изменения кода

### Технические детали

**Движок**: Unreal Engine 5  
**Технология**: GAS (Gameplay Ability System)  
**Язык**: C++ (AttributeSet) + Blueprint (UI и логика)  
**Данные**: Data Asset для конфигурации связей между атрибутами

## Инвентарь

Полнофункциональная система управления предметами с сеткой ячеек, экипировкой, взаимодействиями, крафтом и хранилищем.

### Основной инвентарь

- **Сетка ячеек** — гибкая система с поддержкой разных размеров ячеек
- **Категории** — разделение на Weapon, Equipment, Consumable, Material, Other для быстрого поиска
- **Переноска предметов** — перемещение между ячейками через drag-and-drop
- **Выброс** — выброс предмета из инвентаря в мир (drop)
- **Максимум предметов** — поддержка стека и лимита вместимости для каждого типа

### Экипировка (Paperdoll)

На фигуре персонажа отображаются слоты для экипировки:
- Голова (helmet, crown и т.д.)
- Грудь (chest armor)
- Руки (gauntlets, bracelets)
- Ноги (legs armor)
- Аксессуары (rings, amulets)

Перемещение предмета на соответствующий слот экипирует его, и предмет отображается на модели персонажа.

### Хотбар

- **Быстрый доступ** — 8-10 слотов для быстрого переключения между предметами
- **Использование** — нажатие клавиши (1-9, Q-E) вызывает предмет со слота
- **Drag-and-drop** — перемещение предметов из инвентаря на хотбар

### Крафт

- **Меню крафта** — интерфейс для создания новых предметов
- **Рецепты** — конфигурируемые рецепты через Data Asset (какие материалы нужны, что получится)
- **Требования** — проверка наличия материалов перед крафтом
- **Результат** — создание нового предмета и удаление материалов из инвентаря

### Хранилище (Сундук)

- **Открытие сундука** — взаимодействие с контейнером в мире
- **Два окна** — левое — инвентарь игрока, правое — содержимое сундука
- **Перемещение** — можно переносить предметы между инвентарём и сундуком
- **Сохранение** — состояние сундука сохраняется при закрытии и восстанавливается при открытии

### Архитектура

- **Item system** — базовый класс FInventoryItem с типом, количеством, метаданными
- **Inventory Manager** — управление ячейками, категориями, добавлением/удалением предметов
- **Interaction system** — подсистема для взаимодействия с сундуками и предметами в мире
- **UI binding** — автоматическое обновление UI при изменении инвентаря (event-driven)

### Технические детали

**Движок**: Unreal Engine 5  
**Языки**: Blueprint (основная логика) + C++ (базовые структуры)  
**Данные**: Data Asset для конфигурации рецептов крафта и типов предметов

## Боевая система

Многоуровневая система боя с состояниями на Gameplay Tags и Data Asset конфигурациями. Поддерживает комбо, контекстные атаки в зависимости от движения, и детальную систему получения урона с расчётом точки попадания.

### Состояния атак

Управляются через **Gameplay Tags**, каждому состоянию соответствуют анимации в Data Asset:
- **Обычные атаки** — базовые удары с комбо (до 5 последовательных ударов)
- **Атаки в спринте** — усиленные удары при движении на полной скорости
- **Атаки с прыжка** — урон при падении на врага с прыжка
- **Атаки с присяда** — особые удары из положения присяда
- **Рывки/Дэши** — быстрые перемещение с уроном, можно использовать для избежания

### Система получения урона (HitReaction)

Определяет анимацию реакции врага в зависимости от направления попадания:
- **Forward** — удар спереди, персонаж летит вперёд
- **Back** — удар сзади, персонаж летит назад
- **Right** — удар справа, отброс вправо
- **Left** — удар слева, отброс влево
- **Up** — удар в голову, персонаж летит вверх
- **Down** — удар в ноги, персонаж падает

Расчёт точки попадания происходит через raycast или bone-based система, определяет какую зону (голова, торс, ноги) поразили, и воспроизводит соответствующую анимацию отброса.

### Комбо-система

- **Настраиваемые комбо** — через Data Asset можно создавать комбо любой длины
- **Реактивные комбо** — возможны разные комбо в зависимости от состояния (спринт, прыжок, присяд)
- **Время окна атаки** — между ударами комбо есть окно, где следующий удар будет засчитан как продолжение

### Архитектура

- **Gameplay Tags** — управление состояниями (CombatState.SprintAttack, CombatState.JumpAttack и т.д.)
- **Data Asset конфиги** — для каждого состояния указаны анимации, урон, стоимость манны, скорость атаки
- **HitReaction система** — подсистема расчёта точки попадания и воспроизведения анимаций отброса
- **Event-driven** — изменения состояния вызывают события, на которые подписаны UI и другие системы

### Технические детали

**Движок**: Unreal Engine 5  
**Технология**: Gameplay Tags + GAS  
**Языки**: Blueprint (основная логика) + C++ (HitReaction система)  
**Данные**: Data Asset для конфигурации комбо и анимаций
